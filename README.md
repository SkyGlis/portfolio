# Daniel Santos · portfólio

Portfólio pessoal em PT e EN, com um terminal interativo no topo (escreve `help`).

Feito com Next.js e CSS simples, sem bibliotecas de UI.

```bash
npm install
npm run dev   # http://localhost:3000
```

Todo o conteúdo (projetos, percurso, stack, textos PT/EN) está em [`app/content.ts`](app/content.ts).
Os CVs ficam em `public/CV_Daniel_Santos_PT.pdf` e `public/CV_Daniel_Santos.pdf` (EN) e a foto em `public/photo.jpg`.

Online em [daniel-santos.vercel.app](https://daniel-santos.vercel.app).
